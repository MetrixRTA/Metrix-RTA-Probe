# Changelog

## [0.1.3] - 2026-09-02 (pre-release)

### Added

- Native WASAPI Exclusive stream-format validation
- Native 64-bit ASIO driver inspection
- Per-format buffer size in driver-reported frames and calculated milliseconds
- WASAPI endpoint, shared-format and device-period information
- ASIO channel, clock, sample-position and buffer-constraint information
- Structured, color-coded reports
- Clipboard report export
- Sample-rate checks up to 768 kHz with compatible hardware

### Notes

- This is a pre-release intended for device compatibility testing and diagnostics.
- The application is distributed as closed-source software.
- The application source code is not published.
