# Metrix RTA Probe 0.1.3 — pre-release

Metrix RTA Probe reports the real capabilities of Windows WASAPI and ASIO audio devices. A format is shown as working only after its native stream has opened, initialized and started successfully.

## Highlights

- WASAPI Exclusive validation by format and channel count
- Native 64-bit ASIO driver validation
- Driver-reported buffer sizes in frames with duration in milliseconds
- Device, driver, channel, clock and period information
- Structured reports with color emphasis and clipboard export
- Sample-rate checks up to 768 kHz with compatible hardware
